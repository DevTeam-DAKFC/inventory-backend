# Inventory Backend

Backend REST para el sistema de gestión de inventario.

Este repositorio contendrá:

- ASP.NET Core Web API
- SQL Server
- Docker / Docker Compose
- EF Core
- Swagger / OpenAPI
- Pruebas del backend

La aplicación móvil Flutter vive en el repositorio separado inventory-mobile-project y consumirá esta API mediante Dio / HttpClient.
